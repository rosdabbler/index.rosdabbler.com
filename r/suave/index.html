README

SUAVE: An Exemplar for Self-Adaptive Underwater Vehicles

SUAVE (Self-adaptive Underwater Autonomous Vehicle Exemplar) is a ROS 2 Humble exemplar for self-adaptive robotics. An autonomous underwater vehicle (AUV) searches for a pipeline on the seabed, then follows and inspects it, while its thrusters fail, the water visibility changes, and its battery drains.

SUAVE separates the managed subsystem, which implements the AUV’s mission, from the managing subsystem, which implements the adaptation logic. Any managing subsystem that uses SUAVE’s ROS 2 interfaces can be plugged in, so different adaptation approaches can be compared on the same missions and metrics.

Documentation: https://kas-lab.github.io/suave/

A video of SUAVE running (click the image to open it):

An overview of the system:

Quick start

With Docker installed:

git clone https://github.com/kas-lab/suave.git
cd suave
source env.sh
suave docker run
suave run

suave docker run pulls the headless image and starts a container named suave, and suave run starts an experiment campaign in it. Results are saved to ~/suave/results on the host. Add --gpu none to suave docker run on machines without an NVIDIA GPU.

To try SUAVE in a browser-based desktop instead, or to install it without Docker, see Docker and Installation.

Managing subsystems

Built into this repository:

  • None: no adaptation, a lower-bound baseline.
  • Random: adapts at random intervals, a chance baseline.
  • Metacontrol: ontology-based reasoning with MROS2.
  • Behavior Tree: adaptation logic as a BehaviorTree.CPP tree.

Maintained separately:

  • ROSA: knowledge-based adaptation with TypeDB.
  • Planta: PDDL planning with PlanSys2.

See Implementations for details and Extending SUAVE to connect your own.

SUAVE: An Exemplar for Self-Adaptive Underwater Vehicles

SUAVE (Self-adaptive Underwater Autonomous Vehicle Exemplar) is a ROS 2 Humble exemplar for self-adaptive robotics. An autonomous underwater vehicle (AUV) searches for a pipeline on the seabed, then follows and inspects it, while its thrusters fail, the water visibility changes, and its battery drains.

SUAVE separates the managed subsystem, which implements the AUV’s mission, from the managing subsystem, which implements the adaptation logic. Any managing subsystem that uses SUAVE’s ROS 2 interfaces can be plugged in, so different adaptation approaches can be compared on the same missions and metrics.

Documentation: https://kas-lab.github.io/suave/

git clone https://github.com/kas-lab/suave.git
cd suave
source env.sh

suave run

Managing subsystems

Built into this repository:

  • None: no adaptation, a lower-bound baseline.

  • Metacontrol: ontology-based reasoning with MROS2.
