CHANGELOG

Changelog for package tile_map

4.2.0 (2026-10-30)

  • Adding attribution on map for different sources (#989)

  • Adding an API key for the Carto tile source (#986)

    • Add CartoSource, which appends ?key=<key> to tile URLs

    - Use it for the built-in Carto source, with a "Carto API Key:" field that is applied on Save and persisted as carto_api_key

    - Show an API-key placeholder and tooltip for key-based sources instead of the custom URL template example

    - Document how to get and set a Carto key Co-authored-by: David Anthony <<djanthony@gmail.com>>

  • Improving logic for selecting whether to build against Qt5 or Qt6 (#988)

  • Contributors: David Anthony, Logan Elliott

4.1.2 (2026-09-28)

  • Adding tests for malformed messages, Qt signal connections, and config files (#978)
  • Connecting combo boxes with a signal that exists in Qt 6 (#974)
  • Add unit testing based on recent bug discoveries. (#968)
  • Work around lack of transform equality check (#947)
  • Standardize BSD license headers and enable ament_copyright (#944)
  • Enable cppcheck (#943)
  • Enable cpplint (#942)
  • Reformat C++ with ament_uncrustify and enable uncrustify (#941)
  • Enable flake8 and pep257 (#940)
  • Add ament_lint_auto and pre-commit, enable xmllint and lint_cmake (#939)
  • Contributors: David Anthony

4.1.1 (2026-09-24)

4.1.0 (2026-09-20)

  • Making it easier to build a local tilemap (#929)
  • Fix build warnings (#923)
  • Cleaning up dependencies, versions, scopes, etc. (#920)
  • Contributors: David Anthony

4.0.4 (2026-09-17)

  • Fixing tile map drawn in degrees when the local origin is at lat/lon 0,0 (#910)
  • Fixing tile subdivision grid spanning more than one tile at low zoom (#912)
  • Contributors: David Anthony

4.0.3 (2026-08-22)

4.0.2 (2026-08-15)

4.0.1 (2026-08-13)

4.0.0 (2026-08-12)

  • Switching to prefer Qt5 over Qt6 for systems where both are installed (#899)
  • Add Helper Functions for New Threading Model (#890)
  • Update for Deprecated Functionality (#885)
  • Contributors: David Anthony

3.1.0 (2026-07-08)

  • Dual Support for Qt5 and Qt6 (#873) Adding support for building against both Qt5 and Qt6
  • Adjust UI element size properties to work for higher resolutions/scaling (#879)
    • Update button/text/space fields to work better for a variety of display resolutions and scalings
    • Fix spinboxes for 1080p
  • Tilemap Plugin Peformance/Stability Improvements
