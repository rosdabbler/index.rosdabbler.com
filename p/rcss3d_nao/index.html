README.md

rcss3d_nao

Rcss3d Nao is a ROS2 package that provides an interface to the RoboCup 3D Simulator SimSpark that closely matches a Softbank Nao robot interface.

For more information, see our Documentation

CHANGELOG

Changelog for package rcss3d_nao

1.2.0 (2024-04-14)

  • Publish imu and joint states (#22)
  • Contributors: Kenji Brameld

1.1.0 (2023-09-02)

  • Add x,y,theta parameters to easily set initial position of robot
  • Contributors: Kenji Brameld, ijnek

1.0.0 (2023-08-03)

  • Migrate to nao_lola_sensor_msgs and nao_lola_command_msgs (#20)
  • Contributors: Kenji Brameld

0.1.1 (2022-07-21)

  • Remove source build of rcss3d_agent
  • Contributors: Kenji Brameld

0.1.0 (2022-06-30)

  • Implemented basic functionality
  • Contributors: Kenji Brameld, ijnek
