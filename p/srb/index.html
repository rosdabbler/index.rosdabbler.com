README.md

Space Robotics Bench

Space Robotics Bench (SRB) provides parallel, procedurally generated and domain-randomized simulation environments and tasks built on Isaac Sim and Isaac Lab, with a Gymnasium API and ROS 2 (including Space ROS) interfaces.

Documentation

Start with the SRB documentation: System Requirements → Installation → Basic Usage
